TrendPulse – What's Actually Trending Right Now

Project Overview

TrendPulse is a data analytics mini project that explores YouTube Trending Video Statistics across three countries: United States (US), Great Britain (GB), and India (IN).

The project covers the complete data analysis workflow, including Python fundamentals, NumPy, Pandas, data visualization, exploratory data analysis, SQL, and spreadsheet reporting.

Project Parts

Part 1 – Python Foundations & Data Structures

Covers Python fundamentals, data cleaning, data structures, loops, functions, and video classification.
